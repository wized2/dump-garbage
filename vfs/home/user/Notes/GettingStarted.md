# Getting Started with Endroid OS

### 1. Terminal Tips
Try running these commands in the terminal:
- `neofetch` - Display beautiful OS system info
- `ls -la` - List all files in your home folder
- `uname -a` - Inspect kernel version
- `epk list` - See all installed packages

### 2. Installing Apps (.epk)
You can install `.epk` files by:
1. Double-clicking any `.epk` file in the File Manager.
2. Opening the **App Installer** app and browsing or dropping a file.
3. Using the `epk install <package.epk>` terminal command.
