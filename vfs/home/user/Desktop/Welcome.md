# Welcome to Endroid OS! 🌟

Endroid OS is a lightweight, web-powered operating system built on top of the Linux kernel.

## Features:
- **Web-Powered Desktop UI**: Rendered with HTML5, CSS3, and JavaScript at a fluid 60fps.
- **.epk Package Architecture**: Distribute and install web apps as `.epk` archives with standard `manifest.json`.
- **Offline Lucide Icon Suite**: Crisp, vector icons bundled natively.
- **Local API Server**: JSON communication for file system, processes, and settings.
- **Preinstalled Suite**:
  1. File Manager
  2. Interactive Terminal
  3. Web Browser
  4. Notes & Markdown Editor
  5. Scientific Calculator
  6. .epk App Installer
  7. System Settings

Enjoy exploring Endroid OS!
